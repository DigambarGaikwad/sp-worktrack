Capacity Planning

Date range wise capacity, machine demand, manpower shortage and date-wise employee production plan.

1. Planning Window
Available hours are taken employee-wise from Admin → Employee tab. Planned absent employees are removed date-wise. Completed work up to the day before From Date is reduced from the plan.
2. Machine Demand Builder
Priority is numeric. Plan sorts machines by Priority No. first, then target date, then created sequence. Machine numbers are auto-picked from active Admin machines; if not available, “No number given yet” is used.
3. Department-wise Remaining Requirement
4. Planning Result
5. Generate Production Plan
Date-wise plan uses machine priority, completed production entries, skill confidence, planning efficiency cap, target dates and available minutes per day.
6. Date-wise Employee Production Plan
